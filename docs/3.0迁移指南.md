# 迁移指南

本文旨在帮助用户将 2.x 版本的 pvzclass 更新至 3.0 之后，对相关代码进行适配。

## 3.0 版本的重要更新

- 添加了 `PVZ::PVZString`，用于取代 `Draw::PString`。
  - 影响等级：中
  - 首次发布版本：3.0 alpha 1 
  - 迁移建议：
    - `PVZ::PVZString` 只能显式地从整数构造，不接受隐式转换。因此原本使用 `Draw::PString` 的代码应当设法转换为 `PVZ::PZString` 对象。
    - `Draw::PString` 的值与 `PVZ::PVZString::GetBaseAddress()` 的返回值一般相等，可以据此直接转换大部分相关代码。
- `Draw.h` 下多个函数改为 `PVZ::Graphics` 的成员函数。
  - 影响等级：中
  - 首次发布版本：3.0 alpha 1 
  - 迁移建议：
    - 原本这些函数的最后一个参数为 `graphic`，只需用原本这个参数传入的数值预先构造一个 `PVZ::Graphics` 对象，然后将原本的调用改为成员函数调用即可。
- `Animation::AssignRenderGroupToPrefix` 参数列表调整顺序
  - 影响等级：中
  - 首次发布版本：3.0 alpha 2
  - 迁移建议：
    - 调整所有调用此函数的参数。
- `ProjectileCollisionEvent` 被拆分为 `PVZEvent::ProjectileCollisionEvent` 和 `PVZEvent::ProjectileCollisionEvent`，且返回值性质发生改变。
  - 影响等级：**高**
  - 首次发布版本：3.0 alpha 2
  - 迁移建议：
    - 参照文档，拆分原本对应 `ProjectileCollisionEvent` 的函数。
    - 参照文档，调整拆分后两个函数的返回值。
- 所有 `ThreeStateEventTemplate` 的派生类添加 `_ts` 后缀
  - 影响等级：中
  - 首次发布版本：3.0 alpha 2
  - 迁移建议：
    - 检查所有从 `pvzclass` 中获取的 `ThreeStateEventTemplate` 派生类（更新后它们一般会报错），并将它们重命名。
- 所有参数名为 `indexoraddress` 或 `idoraddress` 的构造函数不再具有按编号构造的功能。此功能由对应类的 `GetByIndex()` 承接。
  - 影响等级：高
  - 首次发布版本：3.0 alpha 2
  - 迁移建议：
    - 可能有大量函数利用了原本的性质，因此迁移难度较大。建议检查项目中所有相关类返回值的函数 。
